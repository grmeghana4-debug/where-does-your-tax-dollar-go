Privacy notice

This starter website does not include user accounts, contact forms, payment processing, advertising trackers, or analytics by default.

Data requests

The calculator sends a public read-only request to the USAspending API to retrieve federal spending data. The request contains the fiscal year and quarter only; it does not send the amount entered in the calculator or personal information.
